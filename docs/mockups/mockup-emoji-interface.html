Interface emoji : atomes & molécules

Deux niveaux de granularité pour naviguer par image cliquable.

Rappel S165 : Atome = un emoji seul, label = concept (🐱 = Chat). Molécule = cluster d'emojis + label domaine (🐱🐶🐦 = Animaux). La navigation par image unifie concepts + tags + domaines sous une interface visuelle.

Atomes = granularité fine (un tag précis) · Molécules = entrée large (un domaine complet) · Mode hybride = navigation 2 niveaux (molécule → atomes du domaine). Ces 3 modes coexistent selon la page : accueil = molécules, explorer = atomes, header chips = atomes.
