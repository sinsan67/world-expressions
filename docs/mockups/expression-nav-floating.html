Option A — Boutons flottants fixes

Flèches gauche/droite ancrées à mi-écran · badge contexte en dessous · mode switcher en bas

🇫🇷 France · Expression
Avoir le cafard
Se sentir déprimé, mélancolique

Sens

Éprouver une profonde mélancolie, un sentiment de tristesse sans raison apparente.

émotions tristesse quotidien

Origine

Née au XIXe siècle dans les milieux militaires français en Afrique du Nord. Le cafard (insecte) symbolisait l'ennui et le mal du pays des soldats.

Exemple d'emploi

« Depuis qu'il a quitté Paris, il a vraiment le cafard. »

Note de design · Les flèches flottantes sont toujours visibles pendant le scroll. Le badge sous chaque flèche indique le contexte actif (🇫🇷 Même pays / 🏷️ argent / 🔍 Résultats). Le switcher de mode en bas de l'écran permet de changer le contexte sans quitter la fiche. Sur mobile : les flèches coexistent avec le swipe (même zone déclenchante).
