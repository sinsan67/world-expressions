Header unifié — World Expressions

Décisions validées · Mockups desktop & mobile · Plan d'implémentation

Contexte & problème

Chaque page avait sa propre gestion du header — la homepage avec sa LangBar (top-right desktop) + wex-mobile-header (mobile), la page expression avec sa navbar maison (logo + pills langue différentes + boutons contextuels), les autres pages sans header unifié. Résultat : look, placement et comportement incohérents selon la page.

Décision : un composant GlobalHeader unique, monté sur toutes les pages, avec responsabilité claire : logo + langue + auth. Les éléments contextuels (← Retour, recherche, dé) restent dans leurs pages respectives.
