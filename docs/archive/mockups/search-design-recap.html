Acte 2 — La question fondamentale

"Qu'est-ce qu'une recherche argent doit retourner ?"

C'est la question qui a tout changé. Deux modes distincts, ou une seule recherche intelligente ? Sinan a posé le vrai problème :

Sinan : "quand je recherche argent, je veux voir toutes les expressions qui contiennent le mot argent dans la langue originale et dans toutes les langues — par exemple 'para' en turc"

La réponse ? Pas deux modes. Une seule recherche, avec trois niveaux de résultats — et des en-têtes qui expliquent pourquoi chaque résultat est là.

🎨

Acte 4 — Le pivot

La langue de la recherche, pas "ma langue"

Deux grandes sections, pas trois. Et une précision qui change tout : si je tape "para" (turc), c'est les expressions turques qui montent en premier — même si mon interface est en français.

🎯
Décision clé
Le libellé "Ma langue" → remplacé par "Langue de la recherche"
La distinction est fondamentale : c'est le mot tapé qui définit la langue, pas le profil utilisateur
🔍
Détection automatique
Post-search : majorité des résultats match_type="exact" → langue détectée
Badge visible · Dropdown si ambiguïté · Fallback "Tout mélanger"
🎨

Acte 6 — Le grand saut créatif

Naissance du "mode emoji"

On avait jusqu'ici parlé de "mode concept" — terme trop technique. Sinan a recadré l'idée d'une phrase :

Sinan : "Moi je l'appelle mode emoji — c'est-à-dire que ça revient à chercher comme si on cherchait une image dans toutes les langues."

Et avec ça, une vision nouvelle : les emojis comme porte d'entrée dans la base de données. Naviguer dans un univers sémantique par l'image plutôt que par le texte.

Acte 8 — UX anti-confusion

Comment l'utilisateur sait où il est

Question piège : si les tags sur les cartes d'expression sont cliquables, et que la barre de recherche affiche parfois du texte et parfois un chip violet — comment l'utilisateur ne se perd-il pas ?

📝
Mode texte
Input editable classique
L'utilisateur peut modifier le mot directement
💜
Mode emoji / domaine
Chip violet non-editable
✕ pour sortir · URL change (/emoji/slug)

Le chip rend le changement de mode visible au premier coup d'œil. L'URL elle-même sert d'ancre de repère.
