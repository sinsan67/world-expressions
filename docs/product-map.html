Défis principaux
Données — asymétrie et qualité
📊
Asymétrie linguistique forte
FR (1 378) domine massivement IT (40) et TR (38). L'app se ressent comme "française par défaut". Risque pour la proposition de valeur cross-lingue. Enrichir IT+TR avant toute nouvelle langue.
actif
🧪
Qualité des traductions IA jamais évaluée formellement
20 paires générées par Mistral Small — zéro validation humaine structurée. 1 erreur connue identifiée (WR) : "avoir le cœur sur la main" ≠ "wear heart on sleeve" (générosité ≠ émotivité). Déclencheur : score humain sur échantillon avant enrichissement massif.
déclencheur: enrichissement
🏷️
Coverage des tags incomplète
1 050 tags normalisés mais nombreuses expressions sans tags ou sous-taguées. Détériore la navigation /concepts et la recherche sémantique. À adresser avec chaque vague d'import.
après enrichissement
Recherche — logique et cohérence
🌉
Concept cross-lingue non défini (Search Reactor)
Question ouverte : chercher "argent" doit-il trouver "para" (TR) via le pont concept ? La réponse détermine toute l'architecture de recherche multilingue. Atelier planifié S59.
S59 — atelier
🐛
2 bugs frontend identifiés (bloqués jusqu'à l'atelier)
Documentés dans search-rethink-workshop.md. Non corrigés volontairement — patcher sans stratégie = risque de régression. Résolution liée à la décision sur le concept cross-lingue.
S59 — avec atelier
Infrastructure — dette technique
⏱️
Cold start Render (~15s de latence)
Render free tier "freeze" l'API après inactivité. Premier hit de la journée : ~15s de latence visible par l'utilisateur. Solution : upgrade Render ($7/mois) ou keep-alive pinger (cron toutes les 5 min).
UX dégradée
📄
Pagination encore Python (pas SQL native)
LIMIT/OFFSET côté Python = requête complète chargée en mémoire. Bloquant dès que la base dépasse 3 000 expressions. Migration SQL native à faire avant d'importer LN-fr (3 127 entrées).
déclencheur: 3k expressions
🛢️
Colonne `type` = mot réservé PostgreSQL
Guillemets forcés partout dans le code. Fragile à la maintenance. Migration de renommage `type` → `kind` : courte mais à planifier dans un sprint calme.
petite migration
Produit — croissance et expérience
📈
Analytics intégrées mais pas activées
Vercel Analytics est dans le code (commit f751a8b) mais pas encore activé dans le Dashboard Vercel. Sans données d'usage réel, impossible de prioriser les features par impact. 1 clic manquant.

Vue bulles dans /concepts uniquement sur écrans larges. Fallback pills sur mobile. Feature B-rate documentée comme limitation. À généraliser quand la priorité mobile monte.
