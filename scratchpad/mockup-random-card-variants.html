3 variantes de la fiche en Random mode — toutes interactives (‹ › pour naviguer, cliquer les cartes)

A · La vraie fiche complète

On réutilise la fiche expression existante telle quelle (origine, tags, expressions liées…), juste coiffée de la barre Random mode. Zéro nouvelle UI, toute la richesse.

🎲 🌍 Tous · ✨ Touscarte 1

B · La carte devinette

Recto : l'expression seule — on devine le sens. Tap : la carte se retourne et révèle la signification. Le Random mode devient un mini-jeu. Lien vers la fiche complète au dos.

🎲 🌍 Tous · ✨ Touscarte 1

C · La carte postale immersive

Plein écran, fond teinté aux couleurs du pays, typographie géante. Le sens se dévoile d'un tap, la fiche complète reste à un clic. Sensation « voyage », très partageable.

🎲 🌍 Tous · ✨ Touscarte 1
Comment choisir : la variante A maximise la richesse et minimise le code (on navigue entre vraies fiches — c'est déjà presque ce qui existe) ; la B transforme le Random mode en jeu de devinette — la plus « delight », et elle prépare le futur Mode Jeu ; la C maximise l'émotion visuelle et donne envie de partager, mais demande le plus de design neuf. Les trois gardent le badge de type bien visible et les flèches ‹ › avec historique. B et C peuvent pointer vers la fiche complète, donc elles n'enferment pas l'utilisateur.
