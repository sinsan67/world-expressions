Les 4 onglets actuels restent, le dé s'insère au centre. Rechercher reste absent du menu mobile (accessible via l'accueil).

Mon avis sur le menu mobile : la variante M2 est la plus cohérente — tu as raison, Rechercher est une action essentielle et son absence sur mobile est une anomalie (le desktop l'a déjà). Déplacer Carnet en haut à droite est un pattern éprouvé (le cœur + badge reste visible en permanence, sur toutes les pages). Le risque : Carnet perd un peu de visibilité — acceptable si l'audience mobile utilise surtout la découverte. M1 est le repli sans risque : on n'enlève rien, on ajoute le dé — mais l'anomalie Rechercher demeure. On peut aussi faire M1 maintenant (avec la feature Random) et M2 dans un second temps, pour ne pas mélanger deux changements de navigation dans la même livraison.
